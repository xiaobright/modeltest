## 关键发现

**5.6 系列边际收益递减：**
- medium → high（+$1.17，+5min）：**+7 分**（ambient 修复）
- high → xhigh（+$3.76，+11min）：**仅 +1 分**（topic 标记）

**GPT-5.5 的执行效率退化：**
- 与 sol xhigh 同强度（xhigh, ~23-24min），结果低 7 分（99→92）
- 花费反而更高（$9.06 vs $7.25），CPI 仅 **10.2 分/刀**——全场最低
- 多花的 token 和时间没有转化为更高分数，而是在反复试错中消耗掉了
- V4 近乎完美缓存命中仍达到 $9.06，并观察到重复表述和工具调用前迟滞
- 最终代码仍有 92/B+；问题是需要更多无效 token 和代理回合，而不是不会做

**V2 缓存补证：**
- V2 5.5：99 请求、约 1280.1 万总 token、90.5% 缓存命中、实际 **$13.5298**
- 若达到 5.4 的 96.4% 命中率，理想成本约 **$10.12**，缓存中断额外成本约 **$3.41**
- V2 5.4 实际成本 **$6.8870**；V2 理想缓存下 5.5/5.4 成本比约 **1.47x**
- V4 5.5/5.4 成本比扩大到 **3.62x**
- 按 5.5 单价约为 5.4 的 2 倍粗略归一，等价工作量比由 V2 理想缓存约 **0.73x**
  升至 V4 约 **1.81x**，价格倍率不足以解释本轮差距
- 跨版本看，5.4 成本下降 **63.7%**，5.5 相对 V2 实付只下降 **33.0%**；若以 V2
  理想缓存成本为基准，5.5 实际只下降 **10.5%**，两者降幅严重不对称

**GPT-5.4 当前单次观测更高效：**
- 同 xhigh 但仅 15 min / $2.50，CPI **36.4 分/刀**
- V2 与 V4 标尺不同，88 → 91 不能单独证明能力升级
- 同一 V4 上，其时间和费用明显低于 GPT-5.5，说明本次代理执行更高效

**同 xhigh 下的三兄弟：**
- luna（$2.11, 99）> terra（$4.00, 95）> sol（$7.25, 99）
- luna 用 sol 29% 的价格拿到相同分数，是本次单次观测中成本最低的 99 分结果

**当前单次观测的甜区：**
- **最佳单次价格结果 → luna high（$1.29, 98）**：CPI 76.0
- **次优单次成本 → terra high（$2.01, 97）**：CPI 48.3
- **预算充足 → sol high（$3.49, 98）**：13 分钟拿 98 分
- **预算敏感 + 最高分 → luna xhigh（$2.11, 99）**：46.9 分/刀
- **追求最高观测分 → sol/luna xhigh（99）**

terra high 97 高于 terra xhigh 95，说明单次方差不可忽略。各关键档位至少重复 3 次后，
才能把“最佳单次观测”提升为稳定推荐。
