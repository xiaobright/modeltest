## Findings

### 做得好的
1. **Auth 满分（F2=12）**：与 WorkBuddy 版一致，PBKDF2 + 随机 token + 全链路拒绝。
2. **迁移零缺陷（F6=10）**：旧库兼容、幂等、不丢数据——同 WorkBuddy。
3. **ESP 真实编译成功**：自定义 MQTT 实现仍能构建出可用 bin。
4. **Sleep / Voice / Regression 全覆盖**：各项满分。

### 主要缺口
1. **`S-ambient`（F3e −5）**：与 WorkBuddy 相同，环境 session 未关。
2. **`E-contract`（F8 −3，3 项）**：使用自定义 `mqtt_min` 绕过了标准 `esp-mqtt` 组件 → CMake REQUIRES 缺 `mqtt`、源码无 `esp_mqtt_client_publish/start` 调用。这是 **WorkBuddy 版没有的问题**（WorkBuddy 用标准 esp-mqtt + mqtt_payload，F8=8/8）。
3. **`P-report`（F1 −2）**：PR 没有独立的 "changed files" 小节。WorkBuddy 版有完整的修改文件列表。
4. **care context 连带失败（F5 −2）**：ambient 导致。

### PR/报告是否诚实
**基本诚实。** 诊断测试结果、编译结果均如实记录。但 PR 结构不完整（缺 changed files 节）且未交代使用自定义 MQTT 而非标准 esp-mqtt 的决策理由。
